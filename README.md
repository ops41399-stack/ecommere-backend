# E-commerce Backend

This is a scalable **E-commerce backend** built with **Node.js**, **Express**, and **MongoDB**. It supports JWT-based authentication, role-based access, and CRUD operations for products, categories, users, and orders.

---

## Features

- **User Authentication**: JWT-based login and registration with roles (Admin / Customer).  
- **Product Management**: Create, read, update, delete products.  
- **Category Management**: CRUD operations for product categories.  
- **Order Management**: Place orders and track order status.  
- **Real-time stock updates** (optional with WebSockets).  
- **Reporting**: Generate daily/weekly/monthly sales and revenue per product/category (optional).  

---

## Tech Stack

- **Backend**: Node.js, Express.js  
- **Database**: MongoDB (local or Atlas)  
- **Authentication**: JWT  
- **Package Manager**: npm
